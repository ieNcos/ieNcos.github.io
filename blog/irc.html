A Simple Introduction of IRC

Recently I try to find something to chat with people around the world, and I find out irc. Another reason is that I don't want to type in wechat APP. I prefer my editor. Anyway, irc is really an interesting thing. So I'll introduce it in this blog.

1. what is it

It's an instant messaging website. It works just like wechat, which means you can send message on it and other people will receive your message immediately, but without message storage. Thus, if you are offline, you will miss the messages sent by other people.

2. structure

There are channels in irc. Each channel is like a wechat group. One can join a channel by send a 'join' command (e.g."/join \#emacs")and then chat with all the people in it. Your message will be received by all the people in the channel.

You can also chat with some specific person if you know their nickname by a 'query' command (e.g. "/query ieNcos"). The nick name is the only way you can find a person. One can change their nickname by 'nick' command (e.g. "/nick henry").

3. reason to use it

  1. One can use 'real' nickname on irc.
  2. I like the way to control irc. i.e. by send commands.
  3. You can chat with people all around the world, hearing some interesting stories.
  4. I can use it in emacs. don't need to open some APP.
